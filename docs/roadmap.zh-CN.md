# 路线图

[English](roadmap.md)

本路线图描述预期阶段，不承诺固定技术栈或交付日期。

## Phase 0 — 架构与领域模型

记录词汇、依赖边界、工程规则与首份 Schema 规范；只解决启动小规模实现所必需的决定。

## Phase 1 — Experience Schema 与 Mock Source

实现经批准的 v0.1 边界，并实现可产生代表性交互轨迹的 CPU-only Mock Source。它用于验证 Domena 抽象，不是模拟器产品。

## Phase 2 — 校验与数据集存储

增加通用校验、本地数据集序列化/读取路径和基础检查/统计；为畸形数据与读写往返建立测试。

## Phase 3 — 首个真实模拟器适配器

在既定来源边界之后接入 ManiSkill 适配器；其安装方式和数据约定必须同核心隔离。

## Phase 4 — 大规模数据处理

仅当工作负载证明需要时，再评估批处理、更丰富的多模态资产、数据集版本、血缘、质量工作流与分布式执行。

## Phase 5 — 控制平面与平台化

考虑注册表、任务、元数据、API 和编排能力。Go 控制平面是可能的未来实现选择，需经独立设计决策。
