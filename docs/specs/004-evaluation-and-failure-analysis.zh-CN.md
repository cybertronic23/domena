# 规范 004：评测与失败分析

[English](004-evaluation-and-failure-analysis.md)

**状态：** 提议中——架构评审前不作为实现依据。

## 范围

定义带溯源的评测与失败案例记录。该契约关联模型/策略及其配置、任务/上下文和评测集版本、指标定义、聚合结果及 Episode/片段证据。

## 要求

- 评测运行记录被评估产物、可用时的代码/配置、任务/上下文、输入数据集或评测集快照、指标定义和执行时间的不可变标识符。
- 结果保留聚合指标及支持性证据链接；没有指标定义或输入版本的指标值不可比较。
- 失败案例可链接一个或多个证据目标，以及具备类型、置信度和可修订性的假设。初始类别包括数据、感知、策略/控制、硬件、环境和采集协议。
- 评测记录可产生反馈建议，但不得仅凭相关性主张因果归因。
- 可复现性要求披露留出/切分策略和相关条件；发布门禁是未来策略，而非硬编码领域逻辑。

## 非目标

- 模型训练、在线评测执行、基准托管、仪表板、发布审批或自动根因分析。

## 验收标准

获批后的本地 Mock 评测能持久化带指标定义和引用 Episode 证据的版本化结果；失败案例与反馈建议可在不修改原始 Experience 或数据集快照的情况下附加。

## 待决定事项

- 模型/策略产物引用格式与最小执行溯源。
- 指标定义表示与兼容策略。
- 失败分类体系的治理、审查工作流以及敏感安全事件的处理策略。
