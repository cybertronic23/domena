# 规范 003：任务上下文与溯源

[English](003-task-context-and-provenance.md)

**状态：** 提议中——架构评审前不作为实现依据。

## 范围

定义使 Experience 可解释、可比较的来源无关上下文引用：任务定义、环境/场景、具身形态/设备、采集协议以及时间/标定上下文；并定义原始与派生资产共用的引用机制。

## 要求

- 上下文以版本化引用的形式存在，不复制进每个 Step，也不成为模拟器特有核心字段。
- 任务定义可标识指令、成功/失败准则、相关物体/条件及版本，但不规定任务语言。
- 采集上下文可记录来源/适配器身份、操作者或自动化角色、协议版本及中断/安全事件，且使用隐私感知标识符。
- 时间溯源应区分顺序与来源时钟，并在提供时记录时钟/同步信息。
- 传感器和坐标系标定可按版本引用；Domena 不创造通用机器人坐标系模型。
- 派生资产保留对输入与上下文版本的引用，使数据集和评测之间形成证据图。

## 非目标

- ROS 消息定义、机器人控制 API、标定计算、通用任务本体论或真实机器人运营系统。

## 验收标准

获批后的实现可让 Mock Episode 引用两个任务/上下文版本；读取者能解析上下文，并在不导入来源 SDK 的前提下拒绝缺失或不兼容引用。

## 待决定事项

- 本地/离线数据集的引用解析与打包规则。
- 操作者与真实世界记录的隐私、保留和脱敏政策。
- 比较同一任务的仿真与真实 Episode 所需最小上下文。
